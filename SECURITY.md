# Security Policy

## Scope

loginscan is a defensive self-audit tool. Only ever run it against systems you own or are
explicitly authorized to test — the tool enforces this with an authorization gate.

## Reporting a vulnerability

If you find a security issue **in loginscan itself**, please report it privately:

- Use GitHub's [private vulnerability reporting](https://github.com/bayraktarulku/loginscan/security/advisories/new), or
- Open a minimal issue that does **not** include a working exploit and ask for a private channel.

Please do not include working exploits or steps that target third-party systems.

We aim to acknowledge reports within a few days and to ship a fix in a patch release.

## Supported versions

The latest released minor version receives fixes. Older versions may not.
